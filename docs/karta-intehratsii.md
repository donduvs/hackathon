# Карта інтеграції

Камертон може працювати окремо або як модуль наявної інформаційної системи. Принцип обміну даними один: до Камертона надходять лише агреговані числа, а з нього виходять лише агреговані результати. Персональні дані між системами не передаються.

## На базі яких систем може працювати модуль

| Система | Що бере Камертон | Що віддає Камертон | Спосіб |
|---|---|---|---|
| Система електронного документообігу закладу | — | звіт DOCX/PDF, прийняті рекомендації як доручення з відповідальним і строком | файл звіту, у перспективі API |
| Єдина державна електронна база з питань освіти (ЄДЕБО) або кадровий облік | кількість здобувачів, НПП і персоналу за категоріями — для розрахунку охоплення опитуванням | — | імпорт чисел, без списків осіб |
| Система управління навчанням закладу (наприклад, Moodle) | частка особового складу, яка пройшла антикорупційне навчання | — | імпорт агрегованого показника |
| Застосунок «Армія+» (для органів, де він використовується) | частка тих, хто пройшов навчальні курси | — | імпорт агрегованого показника |
| Єдиний портал повідомлень викривачів НАЗК | кількість повідомлень і строки розгляду за рік — об'єктивний показник до питання 3.3 «Робота з викривачами» | — | ручне внесення або вивантаження уповноваженою особою |
| Антикорупційний портал НАЗК для уповноважених | — | підсумки оцінювання для звітування уповноваженої особи | звіт PDF/DOCX |
| Система єдиного входу закладу (обліковий запис працівника) | роль користувача: керівник, уповноважена особа, виконавець | — | вхід через обліковий запис закладу замість демо-входу |
| Портал або вебсайт закладу | — | узагальнені результати для учасників і публікація на антикорупційній сторінці | посилання на екран результатів або API |

## Варіанти розгортання

1. **Окремий сервіс у відомчому контурі.** Python і SQLite працюють на одному сервері без доступу до інтернету. Зовнішніх хмарних сервісів, шрифтів чи бібліотек з інтернету застосунок не потребує.
2. **Модуль наявної системи.** Головна система відкриває екрани Камертона за посиланням з єдиним входом або забирає результати через API (`/api/cycles`, `/api/cycles/{id}/summary`).
3. **Спільний сервіс для кількох закладів.** Анкети, чек-лист, заходи й ваги задано у файлах `data/*.json`. Інший орган сектору безпеки і оборони отримує власний набір файлів без зміни коду.

## Чого Камертон свідомо не бере

Списків осіб, прізвищ, посад, номерів підрозділів, IP-адрес і часу відповіді. Для розрахунку охоплення достатньо чисел за категоріями.

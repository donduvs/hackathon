# API

Відкритий API повертає лише агреговані результати завершених циклів у форматі JSON. Окремих анкет API не віддає.

## GET /api/cycles

Перелік циклів оцінювання.

```json
[{"id": 2, "year": 2025, "title": "Оцінювання 2025 року", "status": "closed"},
 {"id": 3, "year": 2026, "title": "Оцінювання 2026 року", "status": "active"}]
```

## GET /api/cycles/{id}/summary

Підсумки завершеного циклу. Для незавершеного циклу повертається код 404.

| Поле | Зміст |
|---|---|
| `cycle` | ідентифікатор і рік |
| `integrity_index` | Integrity Index, 0–100 |
| `maturity_level` | досягнутий рівень зрілості |
| `components` | рівні компонентів «Культура», «Система», «Підзвітність» |
| `implementation_rate` | частка впровадження інструментів за чек-листом |
| `questions` | рівень і медіани груп за кожним питанням |
| `signals` | сигнали для додаткового аналізу з правилом, за яким вони спрацювали |
| `respondents` | кількість відповідей за групами; для груп менше 5 осіб — «< 5» |
| `methodology` | посилання на опис методики |

Приклад: `https://camerton.onrender.com/api/cycles/2/summary`

## Звіти

`GET /report/{id}.docx` і `GET /report/{id}.pdf` — звіт за формою Додатка Г (потрібен вхід у ролі керівника, уповноваженої особи або виконавця).

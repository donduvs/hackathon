# Архітектура

## Компоненти

```
                 ┌──────────────────────── Камертон ────────────────────────┐
Респондент ──QR──▶ Опитування (app/main.py) ──▶ responses (без коду, часу, IP) │
                 │                                   │                       │
Уповноважена ────▶ Цикли, коди, чек-лист             ▼                       │
особа            │                     Розрахунковий модуль (app/engine.py)  │
                 │                     правила: медіани, ваги, рівні, R1–R3, │
Керівник ────────▶ Панель, рекомендації   P1–P2, аналіз чутливості           │
                 │        │                          │                       │
Відповідальний ──▶ Статус виконання      ┌───────────┼───────────┐           │
                 │                       ▼           ▼           ▼           │
                 │                 Звіт DOCX/PDF   API JSON   Діаграми SVG    │
                 │                 (app/report.py) (/api/…)  (app/charts.py) │
                 │                                                           │
                 │  Налаштування: data/questionnaires.json, checklist.json,  │
                 │  measures.json, settings.json (ваги, пороги)              │
                 │  Сховище: SQLite (app/db.py), журнал дій — таблиця audit  │
                 └───────────────────────────────────────────────────────────┘
```

Відповідності модулям із завдання:

| Модуль із завдання | Де в Камертоні |
|---|---|
| Assessment Manager | сторінка «Цикли і чек-лист», `app/main.py` |
| Digital Questionnaire | `/survey`, `/s/{код}`, анкети в `data/questionnaires.json` |
| Integrity Index Engine | `app/engine.py`, сторінка «Методика» |
| Executive Dashboard | `/dashboard`, `/question/{id}` |
| Comparative Analytics | динаміка, радар РГ проти ОС, сигнали R1–R3 |
| Recommendations Engine | правила P1–P2 в `app/engine.py`, сторінка «Рекомендації» |
| Recommendations Tracker | статуси виконання і зміна рівня в наступному циклі |
| Audit Trail | `/audit`, таблиця `audit` |
| Reporting Module | `app/report.py`, `/report/{id}.docx` і `.pdf` |

## Технічні рішення

- **Python, Starlette, SQLite.** Мінімум залежностей, запуск однією командою, жодних зовнішніх сервісів. Підходить для закритого контуру.
- **Діаграми SVG, створені на сервері.** Сторінки не завантажують бібліотек з інтернету й однаково виглядають у звіті.
- **Налаштування у JSON.** Анкети, критерії, заходи, ваги й пороги змінюються без програміста.
- **Адаптивний інтерфейс.** Анкета зручно заповнюється з телефона.

## Безпека

Анонімність на рівні зберігання описано в [anonimnist.md](anonimnist.md). Сесії підписуються секретним ключем зі змінної середовища `IMD_SECRET`. Ключ не зберігається в репозиторії.
